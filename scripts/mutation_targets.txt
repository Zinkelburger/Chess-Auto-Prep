# Mutation-testing targets: `lib file|test file|extra tests to confirm against`
#
# These are deliberately the files that ALREADY look well tested — high line
# coverage and a dedicated test file. A survivor here is the interesting kind:
# the line runs, and nothing would notice if it were wrong.
#
# The THIRD field matters. The cheap pass runs only the second field, because
# a campaign is dozens of test runs and the Flutter lock is machine-wide. But
# almost every file is exercised by more than its same-named test, so a mutant
# that file misses may well be caught next door. Survivors are re-run against
# the third field before being reported, otherwise the score is a lower bound
# and it sends people to write tests that already exist.
